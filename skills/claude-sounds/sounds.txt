# Sound manifest for claude-sounds.
#
# Format:  <slot> <url>
# One slot per line. The installer downloads each URL to
# ~/.claude/hooks/sounds/<slot>.mp3 and the hook plays it by slot name.
#
# Swap any reaction by changing the URL here and re-running the installer,
# or by dropping your own file over ~/.claude/hooks/sounds/<slot>.mp3.
#
# Sources are third-party uploads on myinstants.com. They are fetched to each
# user's own machine at install time and are not redistributed by this repo.
# If a URL 404s, the installer falls back to a macOS `say` voice for that slot.
#
# NOTE: myinstants serves a generic fallback file for dead slugs, so several
# different-looking URLs can return byte-identical audio. The set below was
# de-duplicated by md5; keep that in mind when adding new ones.

# --- completed, scaled by lines written/edited in the turn ---
